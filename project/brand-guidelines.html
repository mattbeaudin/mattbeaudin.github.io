Brand Guidelines

This site was created to be able to manage client brand guidelines without the need of a developer. Individual client styles are controlled via Umbraco CMS.

Content for each client site is also customizable, meaning we can show off client-specific designs and patterns. This was by far the hardest part of this project because of the amount of variations between clients.
