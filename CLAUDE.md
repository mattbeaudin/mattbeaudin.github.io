# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

Personal portfolio site served by GitHub Pages at `matthewbeaud.in` (see `CNAME`). GitHub Pages builds it with Jekyll from `master`; there is no Node and no tests. `_site/` is build output and is not committed.

## Commands

Ruby comes from Homebrew (`brew install ruby@3.3`, then put `$(brew --prefix ruby@3.3)/bin` on `PATH`). Gems are pinned by the `github-pages` gem so local builds match production, and install into `vendor/bundle`:

```sh
bundle config set --local path vendor/bundle
bundle install
just build   # bundle exec jekyll build -> _site/
just serve   # http://localhost:4000 with live reload
```

If native gems fail to link against `GLIBC_2.38` during `bundle install`, the system `gcc` is being used with Homebrew's Ruby; put a `gcc` that points at Homebrew's `gcc-16` first on `PATH`.

## Structure that matters

- **Layouts:** `_layouts/default.html` holds the `<head>`, nav and footer for every page; `_layouts/project.html` adds the `.back` link, `<h1>`, and the figures column. Shared changes go there once. Asset links are plain root-relative paths (`/css/style.css`).
- **Case studies:** `_projects/<slug>.md`, published at `/project/<slug>.html`. Front matter: `title`, `description`, `stack`, `order` (tile order), `figures` (`src`, `alt`, `caption`; images live in `project/images/`). The body is Markdown (`## Situation`, `## Task`, `## Action`, `## Result`).
- **Home:** `index.html` renders one tile per project from `site.projects`, sorted by `order`. The thumbnail is `project/images/<slug>-thumb.webp`.
- **Styles:** `css/style.scss` plus partials in `_sass/` (theme tokens in `_variables.scss`). Jekyll compiles it to `/css/style.css`; no CSS is committed.
- **JS:** `js/main.js` only fills `[data-since]` elements with the years since that year.
- **Sitemap:** generated by `jekyll-sitemap`; don't hand-write one.
- `blog/index.html` is just a redirect to `blog.matthewbeaud.in` and is kept out of the sitemap.
- `_config.yml` excludes `CLAUDE.md`, `docs/`, `justfile`, the Gemfiles and `vendor/` from the build.
